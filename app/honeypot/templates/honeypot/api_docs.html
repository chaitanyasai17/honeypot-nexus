SecureCorp Core REST API (v1)

Internal integration endpoints for telemetry, user provisioning, and service orchestration.

GET /api/v1/users

List active corporate employees and identity directory.

curl -s http://127.0.0.1:8080/api/v1/users
GET /api/v1/config

Retrieve staging configuration parameters and database host settings.

curl -s http://127.0.0.1:8080/api/v1/config
GET /api/v1/tokens

Fetch service access tokens (requires Bearer authorization header).

curl -s -H "Authorization: Bearer test_token" http://127.0.0.1:8080/api/v1/tokens
GET /api/v1/admin

Restricted administrative controller interface.

curl -s http://127.0.0.1:8080/api/v1/admin
